# Election Process Assistant (Implemented)

Interactive CLI assistant that helps users understand election process, timelines, and voting steps in a clear, nonpartisan format.

## Run

```bash
python -m election_assistant.cli
```

## Features

- Intake flow (state, first-time voter status, voting method)
- Personalized roadmap/timeline
- Prioritized checklist
- Topic drill-down FAQ
- Official-source escalation links

## Notes

This assistant intentionally avoids inventing legal deadlines and instead directs users to official election websites for state-specific deadlines and requirements.
